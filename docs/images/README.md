## The engravings

Every plate is an engraving from a public collection. The full list with titles, engravers, dates and object numbers is in StrixUI's `design-system/assets/Wallpapers/README.md`.

| Plate | Engraving | Licence |
|---|---|---|
| Saturnus (banner, desktop, theme picker, search, dock, cheat sheet, settings) | Jacob Binck after Giovanni Jacopo Caraglio after Rosso Fiorentino, Saturnus, from the Gods in Niches, 1530. Rijksmuseum RP-P-1951-178A | Public domain |
| Janus (`gods.jpg`, theme picker) | Robert van Audenaerd after Carlo Maratta, Janus opens the door of the year, 1685 to 1723. Rijksmuseum RP-P-OB-67.432 | Public domain |
| The other gods (lock screen, `gods.jpg`, theme picker) | Jacob Binck after Giovanni Jacopo Caraglio after Rosso Fiorentino, from the Gods in Niches, Rijksmuseum, listed in StrixUI | Public domain |
